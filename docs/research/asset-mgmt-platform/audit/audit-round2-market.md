## 1. 稽核摘要

- 會進簡報的核心數字大多與來源一致：財政部 599,193 人與 41,188 人、中信×BCG 12.3 萬人、繼承 78,324 棟與贈與 52,722 棟、AppFolio Value Added Services 約 76%、貝殼 FY2025 淨營收 RMB 94.6B 與 Carefree Rent RMB 21.9B、Yardi Breeze 現行定價。
- 遺產稅口徑差已解開：11,040 件是「核定徵稅件數」，12,739 件是「實徵件數」。平均每件 289.2 萬元與 20% 稅率 698 件，都以實徵件數為分母。
- 有 4 處錯誤要在進 BRD 前修正：
  1. R10 的 2023 年贈與稅「應納稅 27,014 件（約 11.8%）」錯誤。來源為 20,714 件（約 9.1%），實徵件數 19,899 件。
  2. R10 第 6 節把「20% 稅率 785 件」寫成「遺產稅要繳稅的 785 件」。要繳稅的件數約 1.3 萬件。
  3. R15 引住商董事長的 103.6% 與 32.9%，來源是「包租業營收 12.8 億元、年增 103.6%」與「代管業營收 19.6 億元、年增 32.9%」，屬產業數字。R15 寫成「租賃管理與租賃仲介營收」。「非自住住宅占 21%」原文為「21% 非自有住宅」。
  4. R10 寫「公股銀行與包租代管業者在 2026 年 3 月起簽約」。一銀在 2026-03-25 簽約時已是第三家公股銀行，臺企銀、臺銀更早。
- 市場規模的算術全部正確。問題在口徑：TAM 用租屋家庭（需求端），SAM 用多屋者持有戶數（供給端）。每人戶數在 SAM 用 3.53 戶、在 SOM 用 4 戶。租金在 TAM 與 SAM 用 8,600 元、在 SOM 用 12,000 元。結果是 SOM 在 100% 滲透時大於同租金下的 SAM。
- R13 的模組表格式一致，但收入矩陣大量使用「無」，而筆記沒有定義「無」。多數「無」沒有證據，應改「未查到」。Buildium 298 條路徑可以重現。
- R15 的「首頁未見」都歸為「未查到」，規則一致。深層頁抽查後，台灣房屋與中信房屋在加盟店或門市層級有代管或租賃管理的線索，應從「未查到」改為「部分（門市層級，證據弱）」。信義維持「未查到」。
- R10 與 R15 對「一站式」的描述可以並存：一銀與合庫兩案都是「銀行信託加力興包租代管」的轉介合作。「一站式」是新聞稿用語，實際機制是轉介 SOP。兩份筆記都漏列其他合作銀行。

### 遺產稅口徑說明

- 11,040 件是「核定徵稅件數」，分母是當年核定件數 18.79 萬件，得出 5.87%。
- 12,739 件是「實徵件數」，代表當年實際收到稅款的件數。實徵件數會包含往年核定、當年入庫的案件，所以比核定徵稅件數多。這一點是稽核推論，來源沒有定義。
- 平均每件稅額與稅率級距占比都用實徵件數當分母。
- 簡報要講「每年約多少件遺產要繳稅」，建議用核定徵稅件數（2023 年約 1.1 萬件）。要講「每年稅收」，用實徵淨額。兩者不得混在同一句。

### 4.4 Buildium 298 條路徑與資料模型

- 重現結果：稽核用相同方法（curl 下載 [developer.buildium.com](https://developer.buildium.com/)，regex 抽取帶引號的 `/v1/...` 字串，去重）得到 298 條，與 R13 一致。頁面大小約 11 MB，內嵌 OpenAPI 規格。
- R13 資源群表的路徑數加總為 290 條，少 8 條：`retailcashusers`（2）、`inventoryasset`（單數，2）、`assetservicehistory`（2）、`residentCenterUsers`（1）、`inventorystorages`（1）。建議補進表格，否則讀者加總會對不上。
- 層級：規格有 `/v1/rentals`、`/v1/rentals/{propertyId}`、`/v1/rentals/units`、`/v1/rentals/owners`，沒有 `/v1/rentals/{id}/units`。R13 的描述正確。r3 寫「單位在物件之下（路徑形如 `/rentals/{id}/units`）」，與實際規格不符。
- `/v1/leases` 開頭的路徑有 43 條，與 R13 一致。
- webhook：頁面出現 46 次「webhook」，抽樣都在 OpenAPI 渲染器的 JavaScript（`WebhooksMap`）內。這支持 R13「規格路徑中沒有 webhook 資源」的說法。
- 326 個 endpoint（含 HTTP 方法）：稽核嘗試解析 JSON 計算 operation 數失敗，未能核對。
- 限制：regex 只抓帶引號的字串，理論上可能混入說明文字裡的路徑範例。298 條可重現，但仍屬調研員自行解析，不是官方資源清單。可信度：中高。
