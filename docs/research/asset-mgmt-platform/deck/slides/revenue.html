收入模式

三階段九種收入來源，定價假設全部待訪談

階段收入來源向誰收單位法規前提
Phase 1屋主訂閱多屋者每月，依單位數分級無
Phase 1經理人訂閱代管業、經紀業每月，依管理單位數無
Phase 1電子合約與簽章屋主、經理人每份無
Phase 1物件驗證與謄本歸檔屋主、經理人每物件每次使用者自行上傳謄本
Phase 2買賣案件流程費經紀業、地政士、建經每案件與經紀業合作，由經紀人簽章
Phase 2特約通路分潤建經每案件比照特約地政士加入建經通路
Phase 2自有房源上架屋主每筆固定費不依成交計酬；灰區一函詢
Phase 3資產管理年費高端客戶每戶每年只做清冊、提醒、文件、協調
Phase 3持照者轉介分潤信託銀行、會計師、地政士、產險每成交保險分潤需保險代理或經紀資格

月費制比單位費易懂。附加服務需持牌通道，所以排在後面。定價區間見第 20 頁。

來源：BRD v2 §6
