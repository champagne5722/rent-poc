商業模式畫布

收入來自屋主與經理人訂閱、案件費、高端年費

關鍵夥伴

點點簽、代管業與經紀業、地政士、銀行信託部、建經、產險、內政部與數發部

關鍵活動

證照驗證、合約與文件流程、對帳與報表、協調與合規

價值主張

屋主：一個入口管所有物件與合約，錢的狀態看得到。

經理人：證照驗證與屋主報表，接案不違規。

承租人：出租權源與押金狀態可查。

顧客關係

自助工具加經理人服務；高端客戶由持照方面對面

客群

多屋者；經理人；承租人（免費）；Phase 2 買賣當事人；Phase 3 高端客戶

關鍵資源

產權錨點、持照者網路、簽章能力、案件狀態機

通路

經理人帶屋主進來（B2B2C）；銀行與力興類轉介

成本結構

工程、法務與函詢、憑證與 API 介接費、客服與人工審核、持照者分潤

收入來源

屋主與經理人訂閱、電子合約、案件費、高端年費、轉介分潤

來源：BRD v2 §5
