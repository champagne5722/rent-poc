# 合約不可變：修約走「撤回→衍生新約」，狀態機維持六態

送簽後的合約內容不可變（點點簽任務本身也不允許變更），修約一律走「撤回 → 複製為新草稿（記錄**衍生關聯**）→ 重新送簽」，不做送簽後原地改約、也不在單一合約實體內做版本化（MIL-13 決議）。狀態機**維持六態不擴充**：不加 expired 等狀態；續約機制與到期標示（純顯示層）皆劃出本輪範圍，留待未來 effort。

## Consequences

- Contract 資料模型新增「衍生自（derived from）」關聯，僅在**撤回修約**路徑記錄；拒簽（declined）後的「複製為新草稿」保留為純省時便利，**不**記衍生關聯——拒簽語意上是交易終點，重議視為新交易。
- 合約詳情頁需呈現衍生鏈（新舊合約互連），由「合約詳情頁」票承接。
- 未來續約功能回歸時，預期可沿用同一套「複製＋關聯」心智模型（關聯型別擴充即可），不需動狀態機。
