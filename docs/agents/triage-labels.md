# Triage 標籤

這些 skill 以五個標準 triage 角色溝通。本檔案把這些角色對應到此 repo issue tracker 實際使用的標籤字串。

| mattpocock/skills 的標籤 | 我們 tracker 的標籤 | 意義                             |
| ------------------------ | ------------------- | -------------------------------- |
| `needs-triage`           | `needs-triage`      | 需要維護者評估此 issue           |
| `needs-info`             | `needs-info`        | 等待回報者提供更多資訊           |
| `ready-for-agent`        | `ready-for-agent`   | 規格完整，可交給 AFK agent 處理  |
| `ready-for-human`        | `ready-for-human`   | 需要人工實作                     |
| `wontfix`                | `wontfix`           | 不予處理                         |

當 skill 提到某個角色（例如「套用 AFK-ready 的 triage 標籤」），使用此表右欄對應的標籤字串。

若您實際使用的詞彙不同，直接修改右欄即可。
