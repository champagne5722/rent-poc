# 待法務確認的術語

`GLOSSARY.md`「租賃與法律用語」小節的 8 個詞，定義依台灣民法慣用語整理，尚未經法務確認。確認後從本檔移除對應項目。

| 詞 | 待確認的重點 |
|---|---|
| 租金、押金 | 押金與保證金是否為同一概念，退還與扣抵的用語 |
| 租期 | 起訖日是否含首尾兩日 |
| 終止 | 向將來失效，已履行部分不回復 |
| 解除 | 溯及失效，回復原狀的範圍 |
| 違約金 | 與賠償金的區分 |
| 轉租 | 是否需出租人同意，用語是否沿用「轉租」 |
| 撤銷 | 與平台「撤回」（Void）的界線 |

選用條款名稱「提前解約違約金」使用口語的「解約」。依租賃性質，提前結束租約的法律用語較接近「終止」，請一併確認。
